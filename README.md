Forecasts Grand Theft Auto VI's launch-day Twitch viewers hour by hour, from the shapes of past big game launches. Round 2: the median blends a local-linear fit in launch scale (which extrapolates past the biggest past launch) with a kernel estimate over similar launches, and the spread is calibrated from leave-one-out misses, weighted toward launches of a similar scale — narrow where big launches are predictable, wide where small launches are not.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
